# Weather Dashboard

## 📌 Project Description

The Weather Dashboard is a web application that allows users to search for a city and view its current weather information. It provides a simple and user-friendly interface for checking weather conditions.

## ✨ Features

- 🌤️ Search weather by city
- 🌡️ Display current temperature
- 💧 Display humidity
- 💨 Display wind speed
- ☁️ Display weather conditions
- 📍 City-based weather information
- ❌ Error handling for invalid cities
- ⏳ Loading indicator
- 📱 Responsive design
- 🎨 Simple and user-friendly interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Weather API
